# 判断記録

| ID | 判断 | 理由 | 変更を検討する条件 |
| --- | --- | --- | --- |
| D01 | 白 / ニュートラル / 青の既定パレット | 内容と操作を区別しやすく、ブランド未定の用途に適用しやすい | 対象ブランド、利用環境、検証で別案が優れる |
| D02 | セマンティックな light / dark トークン | UI とコードと説明のずれを減らす | 複数ブランドへのスケールが必要 |
| D03 | ローカルフォントのフォールバック | 日本語を含め外部フォント通信なしで即座に読める | 配布権を確認したブランドフォントを同梱する |
| D04 | 情報を中心としたサイドバーと内容領域 | 多い知識を繰り返し参照する用途を優先 | モバイルなどで常設ナビが作業を妨げる |
| D05 | 44px の主要操作 | タッチとポインタの両方に余裕を持たせる設計目標 | 密度要件と実ユーザー評価を両立する別配置 |
| D06 | 取得・差分検出と採用の分離 | HTML 変更や人気は改善の証明にならない | 根拠と検証を伴う自動レビューの仕組みが整う |
| D07 | 初版トークンは簡潔な独自 JSON | 小さなランタイムと直接参照を優先 | DTCG 対応ツールとの交換が必要 |

DTCG の公開仕様は [2025.10 Format Module](https://www.designtokens.org/TR/2025.10/format/) を参照先とします。進行中の draft を権威ある実装仕様として扱いません。将来の互換形式の追加は、現在の正本を壊さないエクスポータとして行います。
