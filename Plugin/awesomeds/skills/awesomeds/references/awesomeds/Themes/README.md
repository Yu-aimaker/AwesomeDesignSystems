# テーマとブランド拡張

## 共通条件

本文の読みやすさ、意味のある色、操作領域44px、キーボード操作、エラー回復、動きを減らす設定はテーマを変えても維持します。44pxはAwesomeDSの設計基準でありWCAG AAの一律要求値という意味ではありません。

## 標準と用途別の初期案

| テーマ | 想定する目的 | 構成 | 変更値 |
| --- | --- | --- | --- |
| work | 繰り返す作業を進める | 一覧、進捗、隣接する状態 | radius 10 / gap 16 / blue |
| studio | 作品・製品の特徴を理解する | 大きな主対象、短い説明、順送り | radius 2 / gap 24 / neutral |
| learn | 選び、理由を知り、やり直す | 大きな選択肢、直後の説明 | radius 24 / gap 20 / green |

これらは独自の比較例で、実在ブランドのコピーではありません。学習用途で常に緑や丸形を選ぶ規則でもありません。`tokens.json.profiles`が数値の正本です。サイトの設定保存は差分JSONで、完全なDSパッケージではありません。

## ブランド設計の手順

1. 利用者・利用場面・最重要タスク・既存資産を確認する。
2. 印象を形容詞で終わらせない。「精密」なら数値の桁揃え、比較の密度、短い状態変化などに翻訳する。
3. 文字・色・密度・形・動き・文章の6軸で変更理由を書く。
4. 代表画面を一つ作り、標準と比較する。スクリーンショットだけでなく操作を比較する。
5. 採用値、例外、非採用案、確認できなかった点を残す。

## サイト自体の表現

OverviewはAwesomeDSの編集的な見せ方として大きな欧文ロゴタイプを使用。本文と操作デモは通常のサイズを保つ。日本語本文をロゴと同じ負の字間で組まない。黒い導入セクションはテーマのtext/backgroundを反転したもの。デモ内は比較条件を保つため明示的にlightを使用し、サイトのダークテーマから分離する。

## 調査からの判断

[Sparkle Themes](https://sparkle-design.goodpatch.com/guidelines/themes)はトークン領域を独立させています。[Pepabo](https://design.pepabo.com/)も基盤とブランド資産を分けています。AwesomeDSはこの責務分離を採用し、複数の独立した正本が生まれないよう差分で扱います。
